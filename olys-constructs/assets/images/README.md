# Olyss Constructs Assets Directory

This directory stores branding assets, architectural vectors, and high-fidelity photography resources for Olyss Constructs.

### Structure
- `/logo`: Vector SVG monograms and corporate marks
- `/icons`: Architectural line icons and symbols
- `/images`: High-resolution architectural photography (the demo dynamically loads curated 4K Unsplash architectural photography via fast CDN)
